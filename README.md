Como funciona: Criei a função HOME para hospedar o restante das outras funções para que sejam chamadas na tela principal do app, passo alguns parâmetros de formatação para essa função para manter as dimensões e proporções na tela. A função COUNTER seve para exibir o texto do contador na tela, ela também implementa formatações de texto. Já a função SystemCounter é o coração do projeto, nela armazenamos os dados dos valores e a funcionalidade dos botões que são utilizados para realizar a mudança no estado da variável de valor. SystemCounterPreview gera um preview do app para que não seja necessário ficar reiniciando o app a cada atualização nos atributos visuais do App.

Desafios implementados:

Botão de Reset
Impedimento de números negativos
